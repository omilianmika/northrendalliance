# Northren Alliance – Skill Wizard

Wizard: välj skill → datakälla (Shopify) → innehåll → preview → ladda ner / skicka till Klaviyo.

    cp .env.example .env   # fyll i nycklar (valfritt – utan dem körs demo-läge)
    npm start              # http://localhost:3000

Nya skills: lägg en `.md` i `skills/` (frontmatter: name, output `ad`|`email`, description, accent, bg).
